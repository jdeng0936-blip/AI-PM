## 三、登录角色权限矩阵 (3 级 RBAC)

代码实现见 `frontend/src/app/login/page.tsx` 与 `backend/app/middleware/rbac.py`,白皮书定义见 §8.3。

| 维度 | 👑 总经理 (admin) | 👔 经理 (manager) | 👥 员工 (employee) |
|------|------------------|-------------------|-------------------|
| **预置账号** | admin (1 人) | 张毅 (1 人) | 郭震 / 张维 / 陈翔 / 林跃文 / 郑韬慧 / 宋伟承 / 陶群 / 陈家云 (8 人) |
| **日报数据范围** | 全员 | 全员 | 仅本人 |
| **战情驾驶舱** | ✅ 全部 | ✅ 全部 | ❌ |
| **🤖 AI 对话查询** | ✅ **独占** | ❌ | ❌ |
| **用户管理** | ✅ **独占** | ❌ | ❌ |
| **Excel/PDF 导出** | ✅ | ✅ | ❌ |
| **OKR 设定** | ✅ | ✅ 部门内 | ❌ |
| **催报操作** | ✅ | ✅ 部门内 | ❌ |
| **风险登记/审批** | ✅ | ✅ 部门内 | ❌ |
| **提交晨规划/晚复核** | ✅ | ✅ | ✅ |
| **查看个人评分趋势** | ✅ | ✅ | ✅ |
| **登录后首屏** | `/dashboard` | `/dashboard` | `/submit-report` |

> **角色 vs 岗位的关系**:一个员工 = 1 个**登录角色**(决定权限) + 1 个**岗位类型**(决定日报字段差异)。
> 例:郭震 = `employee` 角色 × 研发岗 → 仅看自己日报 + 表单含代码版本号字段。
